# 1. Navicat (Premium) 彻底卸载

> 本文介绍 Navicat Premium 17 的彻底卸载、安装和破解步骤。


## 步骤一：在控制面板卸载

1. 打开控制面板：按“win”键，输入“控制面板”搜索并打开

2. 打开卸载程序：选择“程序”下面的“卸载程序”

3. 右键卸载：找到 Navicat 并右键卸载

## 步骤二：删除安装目录

找到 Navicat 的安装路径，可能是 `C:\Program Files\Navicat` 或 `C:\Program Files (x86)\Navicat`。请根据个人安装情况，找到并删除这些文件夹。例如我是 `D:\Downloads\SoftWares\Navicat Premium 17`

## 步骤三：清除注册表

1. 打开注册表：按“Win+R”键，输入“regedit”打开注册表编辑器。

2. 找到 Navicat 注册表项：在注册表编辑器中，找到 `计算机\HKEY_CURRENT_USER\Software\PremiumSoft\Navicat`，如果是专业版，则找到 `计算机\HKEY_CURRENT_USER\Software\Premiumsoft\NavicatPremium`。

3. 右键删除：右键点击该注册表项，选择“删除”。

## 步骤四：重启电脑

卸载完成后，重启电脑可以帮助清除残留在系统的临时文件。
